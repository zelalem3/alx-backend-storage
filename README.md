# ALX Backend Storage

A set of ALX backend exercises focused on relational databases, document databases, and caching.

## Topics

- Advanced MySQL
- NoSQL concepts and MongoDB
- Redis basics

## Repository structure

| Directory | Topic |
| --- | --- |
| `0x00-MySQL_Advanced` | Advanced SQL and MySQL |
| `0x01-NoSQL` | NoSQL and MongoDB |
| `0x02-redis_basic` | Redis |

Each directory contains exercises and supporting files for its topic.

## Requirements

Requirements vary by project and may include:

- Python 3 and project-specific packages
- MySQL
- MongoDB
- Redis

Use the setup instructions in the relevant project directory. Database exercises may create or modify data, so use a local development environment and avoid pointing coursework scripts at important databases.

## Note

This repository is for educational purposes. Review scripts and queries before running them against any database.
